# weldingQualityMachineLearning
Este se trata de un código como parte de la maestría en Ingeniería de Sístemas de la Universidad Nacional de Colombia en el cual
se pretende identificar, usando diversas fotos propias de un taller de soldadura, cuál de las imagenes corresponde con buena o 
mala soldadura. Para ello se utilizó técnicas propias del Machine Learning tales como Redes Neuronales artificiales y Máquinas de
Vectores de Soporte. En este caso, la red neuronal utilizada fue un perceptrón, la cual evidenció un desempeño algo inferior frente
la máquina de vectores.
